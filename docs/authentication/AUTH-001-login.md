### 1.1 Google OAuth ログイン
- **ID**: AUTH-001
- **概要**: ユーザーが Google アカウントでアプリにログイン
- **アクター**: ユーザー
- **前提条件**: ユーザーが Google アカウントを持っている
- **主要フロー**:
  1. ユーザーが [Google でログイン] をクリック
  2. Google OAuth 認可画面へリダイレクト
  3. ユーザーが GDrive へのアクセスを許可
  4. OAuth コールバック → アクセストークン取得
  5. ホームに遷移、GDrive にアクセス可能に
- **事後条件**: ユーザーがログイン状態になる
- **詳細**:
  - OAuth 2.0 PKCE Flow を使用
  - トークンはサーバー側で秘密管理
  - リフレッシュトークンで自動更新
- **関連API**:
  - `GET /api/auth/login`
  - `GET /api/auth/callback
