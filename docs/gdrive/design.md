### 2.1 GDrive フォルダ構造の表示
- **ID**: BROWSE-001
- **概要**: GDrive 内のフォルダ・ファイルを階層的に表示（Documents風）
- **アクター**: ユーザー
- **前提条件**: ユーザーがログイン状態
- **主要フロー**:
  1. アプリ起動 → ホーム画面表示
  2. ルートフォルダ内のアイテム一覧を取得・表示
  3. 各アイテムに以下の情報を表示:
     - アイコン（📁 フォルダ / 🎥 ビデオファイル）
     - ファイル/フォルダ名
     - ファイルサイズ（ファイルのみ）
     - 更新日時
- **事後条件**: ユーザーがフォルダ内のアイテムを視認できる
- **詳細**:
  - GDrive API で `mimeType="application/vnd.google-apps.folder"` をフォルダと判定
  - 拡張子 `.mp4` のみをビデオとして認識
  - 大容量リスト対応（ページング）
  - キャッシング: 30秒間のメモリキャッシュ
- **制約**: 単一ユーザーのみ（共有ドライブ非対応）
- **関連API**:
  - `GET /api/drive/list`
  - `GET /api/drive/list?folderId={folderId}`

### 2.2 フォルダナビゲーション
- **ID**: BROWSE-002
- **概要**: ユーザーがフォルダを開いて内部を閲覧
- **アクター**: ユーザー
- **前提条件**: フォルダ一覧が表示されている
- **主要フロー**:
  1. ユーザーがフォルダをタップ/クリック
  2. `/api/drive/list?folderId={selectedFolderId}` を呼び出し
  3. フォルダ内のアイテムを取得・表示
  4. パンくずナビゲーションで現在地を表示
- **事後条件**: フォルダ内のアイテムが表示される
- **詳細**:
  - パンくずナビゲーション: Home > Folder1 > Folder2 > ...
  - 各レベルでクリック可能（任意のレベルに移動可能）
  - [戻る] ボタンでも親フォルダへ戻る
- **関連API**:
  - `GET /api/drive/list?folderId={parentId}`

### 2.3 ファイル検索（フォルダ内）
- **ID**: BROWSE-003
- **概要**: フォルダ内でファイル名で検索
- **アクター**: ユーザー
- **前提条件**: フォルダが表示されている
- **主要フロー**:
  1. ユーザーが検索ボックスにキーワードを入力
  2. リアルタイムフィルタリング（クライアント側）
  3. 検索条件にマッチするアイテムのみ表示
- **事後条件**: フィルタ済みのアイテムリストが表示される
- **詳細**:
  - 大文字小文字を区別しない
  - ファイル名の部分一致で検索
  - サーバー側 API は不要（クライアント側フィルタリング）
- **関連UI**: 検索ボックス（フォルダヘッダー）
