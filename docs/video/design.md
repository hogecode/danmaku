### 3.1 動画再生（ストリーミング）
- **ID**: PLAYER-001
- **概要**: GDrive 上の .mp4 ファイルをストリーミング再生
- **アクター**: ユーザー
- **前提条件**: ユーザーがフォルダブラウザで .mp4 ファイルをタップ
- **主要フロー**:
  1. ユーザーが .mp4 ファイルをタップ/クリック
  2. プレイヤー画面に遷移
  3. `/api/video/{fileId}/stream` からビデオストリーミング開始
  4. ビデオプレイヤーで再生
- **事後条件**: 動画が再生される
- **詳細**:
  - HTTP Range ヘッダーでチャンク転送対応
  - シークバーで任意の位置にシーク可能
  - ストリーミング状態をプログレスバーに反映
- **パフォーマンス**:
  - Cloudflare CDN でキャッシング（TTL: 24h）
  - ファイルサイズ: 最大 10GB まで対応
  - ネットワーク速度に応じた自動ビットレート調整
- **関連API**:
  - `GET /api/video/{fileId}/stream`
  - `GET /api/video/{fileId}/meta` (メタデータ取得)

### 3.2 弾幕（コメント）表示
- **ID**: PLAYER-002
- **概要**: 同フォルダの .json ファイルからコメントを読み込み、動画に重ねて表示
- **アクター**: ユーザー
- **前提条件**: 
  - ビデオプレイヤーが開いている
  - 同フォルダに `{videoName}.json` あるいはXMLファイルが存在
- **主要フロー**:
  1. プレイヤー起動時に `/api/danmaku/{fileId}` を呼び出し
  2. JSON ファイルを取得
  3. 再生時刻に応じてコメントをフィルタリング
  4. ビデオの上に弾幕をリアルタイム表示
- **事後条件**: 再生時刻に対応したコメントが画面上を流れる
- **詳細**:
  - コメント種別: `right`（流れる）/ `top`（上部）/ `bottom`（下部）

  - コメント送信機能なし（受信のみ）
- **関連API**:
  - `GET /api/danmaku/{fileId}`

### 3.3 再生制御
- **ID**: PLAYER-003
- **概要**: 基本的な再生制御（再生/停止/シーク/音量）
- **アクター**: ユーザー
- **前提条件**: ビデオプレイヤーが開いている
- **主要フロー**:
  1. ユーザーが再生/停止ボタンをクリック
  2. プレイヤーが再生状態を変更
  3. ユーザーがシークバーをドラッグ → 任意位置へシーク
  4. ユーザーが音量ボタン/スライダーで音量調整
- **事後条件**: 動画の再生状態が変更される
- **詳細**:
  - 再生速度: 0.25x, 0.5x, 0.75x, 1x, 1.25x, 1.5x, 1.75x, 2x
  - 全画面表示: ブラウザフルスクリーン / Web フルスクリーン
  - Picture-in-Picture: 対応
  - キーボードショートカット: スペース/← →/↑ ↓/F/M など
- **プラットフォーム別**:
  - Web: DPlayer 標準機能
  - Mobile: カスタムプレイヤー UI

### 3.4 プレイヤーから戻る
- **ID**: PLAYER-004
- **概要**: プレイヤー画面からフォルダブラウザに戻る
- **アクター**: ユーザー
- **前提条件**: プレイヤーが表示されている
- **主要フロー**:
  1. ユーザーが [戻る] ボタンをクリック
  2. プレイヤー停止
  3. フォルダブラウザ画面に戻る
- **事後条件**: フォルダ一覧が表示される
- **詳細**:
  - 再生位置は保存しない
  - Mobile: ハードウェアバックボタンでも対応
