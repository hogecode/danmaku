## 🚀 使用方法

### ダンマク設定変更
```
コントローラーバー [字幕アイコン] タップ
  → ボトムシート表示
  → スライダー操作
  → [確定] タップ
  → リアルタイム反映
```

### ダークモード切り替え
```
ホーム画面 [プレイヤーを開く]
  → コントローラー [⚙️設定]
  → Dark Mode トグル
  → アプリ全体で切り替え
```

### 再生速度変更
```
コントローラーバー [1.0x] タップ
  → メニュー表示
  → 速度を選択
  → 即座に反映
```
