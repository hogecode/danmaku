## 🎬 コンポーネント仕様

### 1. コントローラーバー

**配置**: ビデオプレイヤー下部

**ボタン配置**（左 → 右）

| 要素 | 機能 | 仕様 |
|------|------|------|
| 再生/一時停止 | 再生制御 | アイコンボタン (24x24) |
| 時間表示 | 現在時刻/総長 | テキスト ("0:00 / 10:00") |
| プログレスバー | シーク操作 | 横幅100% |
| 音量 | 音量調整 | スライダー (横幅80) |
| 画質 | 画質切り替え | ボタン + ドロップダウン |
| 設定 | メニュー表示 | ギアアイコン |
| フルスクリーン | 全画面切替 | アイコンボタン |

**スタイリング**

```dart
// 背景
backgroundColor: Colors.black.withOpacity(0.7);
height: 56.0;
padding: EdgeInsets.symmetric(horizontal: 8, vertical: 4);

// テキスト
textStyle: TextStyle(
  fontSize: 12,
  color: Colors.white,
  fontFamily: 'Roboto',
);
```

---

### 2. ダンマク設定パネル

**トリガー**: 設定ボタン押下

**表示形式**: ボトムシート

**設定項目**

| 項目 | タイプ | デフォルト | 範囲 |
|------|--------|----------|------|
| 不透明度 | スライダー | 1.0 | 0.0 ~ 1.0 |
| 速度倍率 | スライダー | 1.0 | 0.5 ~ 3.0 |
| フォントサイズ | セレクター | medium | small/medium/big |
| 表示/非表示 | トグル | true | - |
| 最大数 | テキスト | 1000 | 1 ~ 10000 |

**UI例**

```
┌─────────────────────────────┐
│ ダンマク設定                 │
├─────────────────────────────┤
│ 不透明度: ◊———————— | 100%   │
│ 速度: ◊——————— | 1.0x        │
│ フォント: [中▼]              │
│ 表示: [OFF/ON]              │
│ 最大数: [1000]              │
├─────────────────────────────┤
│ [キャンセル] [確定]          │
└─────────────────────────────┘
```

## 🎨 カラーパレット

## 📱 レスポンシブ対応

### 画面サイズ別レイアウト

| 画面サイズ | 幅(dp) | レイアウト |
|----------|--------|----------|
| スマートフォン | < 600 | 縦向き最適化 |
| タブレット | 600+ | 横向きも対応 |

### フルスクリーン

**オリエンテーション**: 横向き固定

**ステータスバー**: 非表示

**ナビゲーション**: 自動非表示（一定時間後）

## ✨ アニメーション

### コントローラー表示/非表示

```dart
duration: Duration(milliseconds: 300);
curve: Curves.easeInOut;
opacity: 0.0 → 1.0
```

### ボタンのタップアニメーション

```dart
ScaleTransition(
  scale: Tween<double>(begin: 1.0, end: 0.95).animate(controller),
);
```

## 🎯 ユーザーインタラクション

### タップ操作

| 操作 | 動作 |
|------|------|
| ビデオをタップ | コントローラー表示/非表示切替 |
| 再生ボタンタップ | 再生開始 |
| プログレスバードラッグ | シーク |
| ボタン長押し | (予約) |

### ジェスチャー

| ジェスチャー | 動作 |
|----------|------|
| 縦スワイプ（右） | 音量調整 |
| 縦スワイプ（左） | 明るさ調整 |
| 横スワイプ | シーク（前後） |
