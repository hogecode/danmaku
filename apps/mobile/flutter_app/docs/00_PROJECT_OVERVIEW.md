## プロジェクト概要

### 目的

既存の web 上で動作する DPlayer (TypeScript + HTML5 danmaku video player) を Flutter で再実装し、iOS/Android モバイルデバイスで同等の機能を提供する。

### 背景

現在のシステムアーキテクチャ:
```
danmaku/ (root)
├── apps/
│   ├── web/              # Next.js + DPlayer (既存)
│   ├── mobile/
│   │   ├── DPlayer-master/       # 参考実装 (TypeScript)
│   │   └── flutter_app/          # ← 本プロジェクト
│   └── server/           # NestJS Backend (既存)
```

### スコープ

**本プロジェクトの責務:**
- Flutter ベースのダンマク動画プレイヤーの実装
- バックエンド API との連携
- iOS/Android ネイティブ機能の統合

**実装対象外:**
- バックエンド API の実装（既存サーバーを使用）
- ウェブ版の更新

## 要件

### 機能要件

#### 1. ビデオ再生機能 (Core)

| 要件 | 詳細 |
|------|------|
| MP4 再生 | 単一形式のサポート |
| 再生制御 | 再生・停止・一時停止・シーク |
| 再生速度 | 0.25x ～ 2.0x (8段階) |
| 音量制御 | 0% ～ 100% 連続調整 |
| フルスクリーン | 横向き・縦向き対応 |
| 画質切り替え | 複数の URL でサポート |

#### 2. ダンマク（弾幕）機能 ← **本機能の核**

| 要件 | 詳細 |
|------|------|
| 弾幕描画 | CustomPaint で Canvas 描画 |
| 複数タイプ | right（右→左）/ top（上）/ bottom（下） |
| サイズ対応 | big / medium / small |
| 色制御 | RGB/HEX カラー指定対応 |
| 不透明度 | 0% ～ 100% 調整可能 |
| コリジョン検出 | 重複表示を自動回避 |
| 速度制御 | 倍速（1.0x ～ 3.0x）対応 |
| 最大数制限 | 1000個上限 (設定可) |

#### 3. API 連携

| 要件 | 詳細 |
|------|------|
| ダンマク取得 | GET `/api/danmaku?video_id=xxx` |
| HTTP 通信 | Dio ライブラリで実装 |
| エラーハンドリング | タイムアウト・ネットワークエラー対応 |

#### 4. UI/UX 機能

| 要件 | 詳細 |
|------|------|
| コントローラーバー | 再生/シーク/音量 |
| 設定パネル | 再生速度・不透明度設定 |
| ダンマク設定 | フォント・色・速度変更 |
| 多言語対応 | 日本語・英語 |

### 非機能要件

| 要件 | 詳細 |
|------|------|
| **パフォーマンス** | 1000+ ダンマク同時表示で 60fps 維持 |
| **メモリ** | 最大同時表示数制限（デフォルト: 1000） |
| **互換性** | iOS 12+ / Android API 21+ |
